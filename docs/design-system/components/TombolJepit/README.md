Tombol tahan JEPIT dan meter RAD, khusus mini-game Uranium (Pemburu Geiger).

**Tombol JEPIT**: lingkaran `tombol-jepit` (120 unit) di kanan layar setinggi ibu jari; area sentuh diperluas 24 unit ke segala arah. Muka `kertas-100`, garis `garis-tebal`, bibir 6 unit. Saat ditahan, tombol turun dan lingkaran `sda-uranium` di dalamnya membesar dari 0 sampai penuh dalam 1 detik. Jika HP terguncang (> 0,35 g), lingkaran kembali ke 0 dan kotak status menjadi AWAS: JEPITAN LEPAS! PEGANG HP STABIL. Selama ditahan, layar tidak bisa digeser.

**Meter RAD**: kotak status dengan tag RAD `sda-uranium`, angka 0-100 dalam `angka-besar`, bar tebal hijau. Label tren "SINYAL MENGUAT ↑" / "SINYAL MELEMAH ↓" (panah ikut ditulis). Selama fase ambil, meter menunjuk serpihan terdekat.

Bar DOSIS memakai Bar ukur (oker, lalu stempel di atas 75%) di dasar layar, bersama penghitung "n/3" serpihan.
