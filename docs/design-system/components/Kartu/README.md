Kartu kertas bergaris tinta dengan selotip kraft di atasnya; wadah untuk semua sheet, panduan, kuis, hasil, kartu target radar, dan peringatan.

**Struktur**: `kertas-100`, garis `garis-tinta`, `radius-lg`, `bayang-kartu`. Padding atas `space-6` (memberi ruang untuk selotip), sisi dan bawah `space-4`.

**Selotip** menggantikan pita judul (ribbon) versi lama. Teks `selotip` huruf kapital, isian `kraft-400`, miring −2°. Varian:
- kraft: judul biasa (PENGATURAN, LATIHAN, PANDUAN, HASIL ANALISIS, nama SDA di panduan).
- merah (`stempel`): judul peringatan dan gagal (IZIN LOKASI DITOLAK, EMAS TERBUANG!, SALAH, WAKTU HABIS).
- hijau (`hutan`): BENAR!.
- kiri: miring −3° di sudut kiri, untuk kartu kecil seperti catatan.

**Varian isi**: `--garis` memberi garis buku tulis setiap 28 unit, untuk teks panjang (panduan, penjelasan). `--benar` dan `--salah` mewarnai muka kartu umpan balik.

Sheet di Lobby memakai kartu ini, naik dari bawah, di atas tirai `redup`. Ketuk di luar kartu menutup sheet.

Jangan: menaruh dua selotip di satu kartu; selotip dengan lebih dari 4 kata.
