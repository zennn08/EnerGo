Kartu spesimen satu SDA, seperti label koleksi di jurnal peneliti: nomor katalog, ikon, nama, dan jumlah unit.

**Struktur**: lebar 132 unit, latar `sda-*-muda` lewat `--muda`, garis `garis-tinta`, `radius-md`, `bayang-tile`. Nomor katalog kiri atas dalam `data` (No.01 Matahari, No.02 Batu Bara, No.03 Emas, No.04 Minyak Bumi, No.05 Uranium; Acak memakai "???"). Ikon `ikon-lg`. Nama `isi-tebal` 16 unit. Badge jumlah unit di pojok kanan atas (lihat Pil).

**State**
- normal: di Lobby hanya tampilan (tidak bisa diketuk).
- terpilih (sheet Latihan): cincin `oranye` `garis-tebal` + label DIPILIH di bawah tile.
- terkunci: garis putus, isi pudar `opasitas-terkunci`, gembok di tengah. Tetap didesain walau kelima SDA sudah terbuka.
- Acak: tanpa badge, latar `sda-acak-muda`.

**Grid**: Lobby 3 + 2 (baris kedua di tengah), Latihan 3 × 2, Panduan 3 + 2. Celah `space-3`.

Jumlah 0 tetap ditampilkan sebagai badge "0" supaya pemain tahu SDA itu belum ditemukan.
