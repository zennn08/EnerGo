Toggle dan slider untuk sheet Pengaturan, disusun dalam baris pengaturan (judul + sub-label di kiri, kontrol di kanan).

**Baris pengaturan**: judul `isi-tebal`, sub-label `kecil` warna `tinta-pudar`. Sub-label berubah mengikuti state (nyala: "HP bergetar saat main", mati: "Mati: tanpa getaran"). Pemisah garis putus `garis-kertas`.

**Toggle**: 64 × 36 unit, garis `garis-tinta`. Mati: track `kertas-300`, kenop di kiri berisi ✕. Nyala: track `hutan`, kenop di kanan berisi ✓. Posisi kenop dan tanda di dalamnya membawa arti, jadi tidak bergantung pada warna. Seluruh baris bisa diketuk, bukan hanya toggle.

**Slider volume**: ikon suara di kiri, bar ukur dengan isian `laut`, kenop bulat `kertas-100` dengan bibir 3 unit, persen di kanan dalam `data`. Saat dilepas, putar contoh suara klik.

**Konfirmasi hapus** memakai tombol, bukan kontrol ini: lihat Tombol (kertas · teks bahaya → bahaya).
