Mockup sheet Pengaturan, sheet Latihan, dan kartu Panduan.

- **Pengaturan**: sheet kartu dari bawah di atas tirai `redup`. Baris toggle Mode AR, slider volume, toggle Getaran, tombol info LATIHAN, tombol reset dalam state konfirmasi (bahaya, dengan bar 3,5 detik yang menyusut), tombol utama SELESAI.
- **Latihan**: grid 3 × 2 tile spesimen termasuk Acak, Emas terpilih, tombol MULAI LATIHAN.
- **Panduan (mode main)**: kartu bergaris di atas kamera yang diredupkan, LANGKAH n/N, ilustrasi, judul, isi, titik halaman, kotak "Jangan ingatkan lagi", LEWATI + LANJUT (MULAI di halaman terakhir). Mode baca mengganti tombol menjadi TUTUP dan menghilangkan kotak centang.

Ilustrasi panduan digambar sebagai sketsa jurnal: garis `tinta`, isian kertas/kraft, satu warna aksen, satu coretan `catatan`. Contoh di sini untuk Emas langkah 2; 12 ilustrasi lain mengikuti gaya yang sama.
