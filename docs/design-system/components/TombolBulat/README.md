Tombol bulat ikon dengan label di bawahnya, untuk dock di bagian bawah Lobby.

**Struktur**: lingkaran `tombol-bulat` (80 unit), garis `garis-tinta`, `bayang-tombol`, ikon 36 unit. Label `isi-tebal` 15 unit di bawah, selalu tampil.

**Isi dock**: Panduan (buku, isian `oker`), Latihan (target, `laut-muda`), Pengaturan (gir, `kertas-100`). Desa (rumah, `kertas-100`) ditambahkan saat Desa Teknik dibuat; dock maksimal 4 tombol.

State ditekan sama dengan Tombol. Label tidak boleh disembunyikan: ikon saja tidak cukup jelas untuk pemain baru.
