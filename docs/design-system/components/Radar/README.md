Piringan radar sebagai kertas milimeter bundar: grid `grid-peta`, cincin jarak 50 m dan 100 m putus-putus, arah mata angin di tepi, pemain di tengah. Heading-up: bagian atas selalu arah HP menghadap, dunia yang berputar.

**Struktur**: diameter 400 unit (radius = 150 m), muka `kertas-100`, garis `garis-tebal`, `bayang-kartu`. Label jarak dalam `data` warna `tinta-pudar`. Huruf U/T/S/B dalam `judul` 18 unit, U berwarna `stempel`; ikut berputar dengan dunia. Garis sapuan berupa irisan `oranye` transparan yang berputar 90°/detik. Pemain: bulatan `oranye` 22 unit + kipas ±35° ke atas.

**Node SDA**: bulatan kertas berisi ikon SDA.
- di luar jangkauan: 44 unit.
- dalam jangkauan (≤ 20 m + bonus akurasi): 58 unit + cincin `oranye`. HP bergetar 60 ms saat node baru masuk jangkauan.
- terpilih: cincin tambahan `tinta`. Bawaan memilih yang terdekat; ketuk node untuk memilih.
- uranium: cahaya `uranium-nyala` berdenyut di belakang node.
- terkunci: garis putus, ikon pudar, tombol kartu target menjadi SEGERA HADIR.

Di atas radar: tombol kecil "‹ LOBBY" dan pil `data` "SPAWN BARU mm:dd". Di bawahnya: pil info kompas/GPS (lihat Layar Radar) dan Kartu target.
