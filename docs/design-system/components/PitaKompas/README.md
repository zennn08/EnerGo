Pita kompas berbentuk penggaris kertas di bawah header layar tangkap, menunjukkan ±60° di sekitar arah pandang dan posisi SDA.

**Struktur**: tinggi 52 unit, `kertas-100`, garis `garis-tinta`, `radius-sm`. Garis skala besar tiap 15° dan kecil tiap 3°. Label arah (U, TL, T, TG, S, BD, B, BL) tiap 45° dalam `data` tebal; U berwarna `stempel` supaya utara selalu mudah ditemukan. Garis tengah `tinta` 4 unit dengan segitiga di bawah = arah pandang.

**State**
- titik: SDA sebagai bulatan `oranye` bergaris tinta. Untuk batu bara, titik menunjuk bongkahan terdekat.
- penanda tepi: SDA di luar ±60°, label `oranye-tua` di tepi kiri "‹ 75°" atau kanan "75° ›" berisi sisa sudut.
- sektor: khusus Uranium, pita hijau transparan ±45° dengan tepi putus `hutan`, tanpa titik pasti.
- mati: arsiran diagonal dengan teks KOMPAS TIDAK TERSEDIA.

Pita ini selalu di atas kamera, jadi selalu kertas terang; jangan dibuat transparan.
