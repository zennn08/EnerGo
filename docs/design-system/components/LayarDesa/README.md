Mockup Desa Teknik (fitur direncanakan): desa menyala dan desa padam.

- **Menyala**: judul DESA **TEKNIK**, pil level `oker`, sketsa desa dengan jendela `sda-matahari` dan pembangkit, kartu Pembangkit dengan bar stok `oker` (maks 24 j), deret SDA dengan durasi per unit (+20m, +30m, +20m, +45m, +3j), tombol ISI BAHAN BAKAR. Level 1-3 hanya menampilkan Batu Bara dan Emas di deret ini.
- **Padam**: latar malam, rumah gelap, cap PADAM, kartu berselotip merah LAPORAN SINGKAT dengan stok 0 dan langkah pemulihan, tombol BERBURU SDA. Saat stok < 3 jam (belum padam), Laporan Singkat memakai selotip kraft dan baris peringatan `oranye-tua`.

Warna latar malam di mockup ini adalah sketsa dan belum dijadikan token; tambahkan tema "Malam" jika layar ini jadi dibuat.
