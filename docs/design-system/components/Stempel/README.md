Cap karet bergaris ganda yang "dicap" ke kartu untuk menandai penilaian: benar/salah, kualitas Murni/Normal, nilai mini-game.

**Struktur**: teks `selotip` (versi sempit), garis luar `garis-tebal` + garis dalam 1,5 unit dari warna yang sama, `radius-sm`, miring. Latar kertas setengah transparan supaya garis di bawahnya tetap terlihat.

**Varian**: `--benar` (`hutan`, miring +7°), bawaan merah (`stempel`, −8°), `--normal` (`tinta-pudar`). Ukuran `--kecil` untuk chip di hasil dan `--besar` untuk kualitas MURNI.

**Pakai di**: cap BENAR/SALAH yang muncul saat kartu soal digeser; cap MURNI atau NORMAL di kartu hasil; nilai mini-game (HEBAT +2, BAGUS +1, CUKUP +0).

**Animasi** (di Unity): muncul dari skala 140% ke 100% dalam 0,12 detik dengan sedikit putaran, bersamaan getar 30 ms (benar) atau 200 ms (salah).

Selalu tulis katanya. Warna saja tidak cukup untuk membedakan benar dan salah.
