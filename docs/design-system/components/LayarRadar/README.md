Mockup Radar, peringatan keselamatan, dan error GPS.

- **Radar**: baris atas "‹ LOBBY" + pil SPAWN BARU, piringan radar 400 unit, pil info dua baris (kompas, GPS), kartu target dengan TANGKAP. Saat sinyal lemah, baris GPS menambah "· Sinyal lemah, coba ke tempat terbuka" dalam `oranye-tua`; tanpa kompas, baris pertama menjadi "Kompas tidak tersedia, utara di atas".
- **Peringatan keselamatan**: kartu berselotip merah HATI-HATI DI JALAN di atas tirai, ilustrasi kerucut, tombol SAYA MENGERTI. Muncul sekali per instalasi sebelum radar bisa dipakai.
- **GPS gagal**: radar dipudarkan (grayscale), kartu berselotip merah dengan judul state, penjelasan, catatan, tombol COBA LAGI (info) dan MAIN MODE LATIHAN (kertas). Izin ditolak dan lokasi mati memakai susunan yang sama dengan judul dan isi dari PRD. "Mencari sinyal GPS..." memakai radar yang sama tanpa node dan teks `status` di bawahnya, tanpa kartu.
