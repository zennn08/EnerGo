Mockup kuis, umpan balik, dan hasil.

- **Kuis**: penanda 3 soal, pil SOAL n/3, judul BENAR **ATAU** SALAH?, kartu soal digeser ke kiri dengan cap SALAH dan cincin `stempel`, pendar `stempel` di tepi kiri layar, tombol SALAH (kiri) dan BENAR (kanan).
- **Umpan balik**: kartu muka `stempel-muda` berselotip SALAH, chip yang menyebut jawaban benar, penjelasan + sumber sebagai `catatan`, tombol BACA DULU... terkunci 2 detik.
- **Hasil**: judul besar (SEMPURNA! / BAGUS! / COBA LAGI), kartu HASIL ANALISIS dengan 3 bintang (tengah lebih besar, `bintang` / `bintang-kosong`), "n/3 BENAR", ikon SDA + "+N" `angka-besar` + cap MURNI (`hutan`) atau NORMAL (`tinta-pudar`), chip rincian, pesan, tombol LANJUT BERBURU / LANJUT KE LOBBY.
