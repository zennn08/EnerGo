Mockup layar tangkap untuk Matahari (Ekstraksi), Batu Bara (Tambang), dan Emas (Dulang). Semua HUD adalah kertas terang di atas kamera.

- **Ekstraksi**: header, kotak status AMAN dengan bar cahaya `sda-matahari`, pita kompas dengan titik, lingkaran bidik terkunci menangkap matahari, tombol MUNCULKAN ULANG TARGET. Saat matahari > 28° di samping, kotak status menulis "‹ PUTAR KE KIRI 40° · SISA 12 DTK".
- **Tambang**: bongkahan berukuran sesuai jumlah ketukan, deretan pip di atas masing-masing (`oranye` = ketukan masuk), cincin ketukan `oranye` di titik sentuh, label kamera menunjuk bongkahan yang tersisa.
- **Dulang**: pil EMAS n/18 `oker`, dulang dengan air `peta-air` dan keping `sda-emas`, keping yang terlempar keluar saat terlalu kasar, kotak status AWAS. Fase datar memakai gelembung waterpass (cincin + gelembung berubah `hutan` saat datar); hitung mundur memakai `angka-besar` di kartu "SIAP?"; gagal memakai kartu berselotip merah EMAS TERBUANG! dengan tombol CARI ENDAPAN BARU.
